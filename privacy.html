1. Uygulamanın Amacı

Live Dashboard, YouTube canlı yayınlarının yönetimini ve takibini kolaylaştırmak amacıyla geliştirilmiş kişisel bir yayın kontrol uygulamasıdır.

Uygulama, YouTube Data API aracılığıyla canlı yayın sohbet mesajlarını alır ve yayın yöneticisinin bu mesajları tek bir kontrol paneli üzerinden gerçek zamanlı olarak görüntülemesini sağlar.

2. Google ve YouTube Verilerinin Kullanımı

Live Dashboard, Google hesabı üzerinden verilen izinler kapsamında YouTube canlı yayın sohbet verilerine erişebilir. Bu veriler yalnızca aşağıdaki amaçlarla kullanılır:

  • YouTube canlı yayın sohbet mesajlarının görüntülenmesi.
  • Sohbet mesajlarının gönderen kullanıcı adlarıyla birlikte gösterilmesi.
  • Canlı yayın sırasında izleyici etkileşimlerinin takip edilmesi.
  • Yayın kontrol panelinde sohbet akışının sunulması.

Uygulama, YouTube verilerini reklam hedefleme, kullanıcı profilleme veya pazarlama amacıyla kullanmaz.

3. Veri Saklama ve Paylaşımı

Live Dashboard, kişisel kullanım amacıyla geliştirilmiştir. YouTube canlı sohbet verileri, uygulamanın yayın kontrol panelinde görüntülenmesi amacıyla işlenir.

Uygulama geliştiricisi, bu verileri reklam verenlere satmaz veya pazarlama amacıyla üçüncü taraflarla paylaşmaz.

OAuth erişim bilgilerinin saklanması ve sohbet verilerinin tutulma süresi, uygulamanın teknik yapılandırmasına bağlıdır.

4. Google Hesabı Yetkilendirmesi

Live Dashboard, YouTube hizmetlerine erişebilmek için Google OAuth 2.0 kimlik doğrulama sistemini kullanır. Kullanıcılar Google hesapları üzerinden uygulamaya gerekli izinleri verir. Uygulama, kullanıcının Google hesabı parolasını talep etmez.

Verilen erişim izinleri Google hesap bağlantıları sayfasından geri alınabilir.

5. Veri Güvenliği

Live Dashboard, yalnızca yetkilendirilmiş kullanıcıların yayın verilerine erişmesini hedefler. Google OAuth üzerinden alınan erişim bilgileri, YouTube API bağlantısının kurulması ve sürdürülmesi amacıyla kullanılır.

6. Kullanıcı Hakları

Kullanıcılar, Live Dashboard uygulamasına verdikleri Google hesabı erişim izinlerini istedikleri zaman iptal edebilir. Verilerin silinmesi veya gizlilikle ilgili talepler için uygulama geliştiricisiyle iletişime geçilebilir.

7. Google API Hizmetleri

Live Dashboard, YouTube verilerine erişmek için Google API Services kullanır. Uygulamanın Google API üzerinden elde ettiği verilerin kullanımı, Google API Services User Data Policy kapsamında değerlendirilir.
